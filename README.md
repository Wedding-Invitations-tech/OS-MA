# Regal Plum Continuum

This build preserves the original envelope and opening animation.
After opening, the invitation unfolds as a single continuous cinematic scroll experience in the Option 1 plum colourway.

## Features
- original envelope retained
- automatic opening after 3 seconds if untouched
- continuous scroll transitions between invitation, date/location and programme
- Google Maps hotspot on the location button

## Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000
